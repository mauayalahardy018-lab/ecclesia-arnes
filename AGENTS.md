# Mantenimiento del arnés

Este repositorio contiene instrucciones reutilizables; el proyecto Ecclesia vive en el repositorio hermano. Leer `README.md`, `ARCHITECTURE.md`, `CHANGELOG.md` y el checklist de revisión antes de cambiar reglas. Cada cambio del arnés debe provenir de una necesidad o un error observado, describir qué se corrigió y cómo se verificó. Mantener ejemplos genéricos, sin contraseñas ni datos personales. No atribuir al cliente respuestas que no haya dado ni completar la bitácora con entradas inventadas.

La instalación en un proyecto copia `core/AGENTS.base.md` como `AGENTS.md` y adapta `plantilla-proyecto/PROYECTO.md`. El archivo de esta raíz regula el mantenimiento del arnés, no se copia al producto.
