# Definición de terminado

- [ ] RF/RN y origen del caso indicados; dudas del cliente documentadas.
- [ ] Criterios de aceptación automatizados o marcados como pendientes con motivo.
- [ ] Validaciones de entrada, rol y alcance por iglesia probadas.
- [ ] Migración y seed cuando cambian los datos.
- [ ] OpenAPI y README actualizados cuando cambia el contrato.
- [ ] Lint, formato, pruebas, cobertura y reglas de dependencias verdes.
- [ ] `npm run coverage:full` supera 70 % en dominio y servicios con base sembrada, si se tocaron esas capas.
- [ ] Si el catálogo usa templos reales, fuente y enlace Maps funcionan; datos operativos simulados quedan identificados.
- [ ] Con base embebida, lecturas paralelas pasan y los límites de esa prueba se documentan; concurrencia crítica se valida en servidor PostgreSQL.
- [ ] Hook `pre-commit` instalado y comprobado antes de publicar el repositorio.
- [ ] Revisión humana de seguridad, privacidad y montos.
- [ ] Bitácora y trazabilidad actualizadas con resultados reales.
