# Prompt para un módulo nuevo

Lee `AGENTS.md`, `ARCHITECTURE.md`, `docs/requerimientos.md` y el módulo Iglesias. Implementa [RF] y sus [RN]. Primero enumera archivos, permisos, validaciones, migración, pruebas y preguntas abiertas. Después crea el cambio por capas, ejecuta `npm run check` y actualiza trazabilidad y bitácora con resultados reales.
